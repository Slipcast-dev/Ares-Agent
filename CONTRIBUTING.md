# Contributing / Участие

## Русский

Обсуждения и обращения принимаются на русском и английском. Для ошибки используйте
Bug report, для идеи — Feature request. Укажите версию, macOS/архитектуру, шаги,
ожидаемый и фактический результат. Приложите только обезличенные данные.
Проблемы безопасности сообщайте через [SECURITY.md](SECURITY.md).

Перед PR прочитайте [лицензию](LICENSE). Технический fork разрешён только для PR
в исходный репозиторий; публикация производных сборок требует письменного разрешения.
Делайте небольшие изменения. Выполните сборку, доменные/общие тесты и проверку
snapshot; опишите проверки и ограничения. Не добавляйте ключи, БД, bookmarks,
личные профили, установщики, внутренние промпты или локальные заметки.

## English

Russian and English reports are welcome. Use Bug report or Feature request and
include version, OS/architecture, steps, expected/actual behavior and sanitized
evidence. Security reports follow [SECURITY.md](SECURITY.md).

Read the [license translation](LICENSE.en.md) before contributing. A technical fork
is permitted solely for a PR to the original repository; derivative distribution
requires written permission. Keep changes focused, build and test the domain and
shared package, verify snapshot hashes, and state validation/limitations. Do not
include secrets, databases, bookmarks, personal profiles, installers, private
implementation prompts or local notes.
