# Установка и удаление / Lifecycle

Установка не выдаёт разрешения автоматически. Автозапуск — отдельное GUI opt-in.
При удалении сначала остановите агент и используйте штатное обслуживание;
пользовательские данные и резервные копии сохраняются.

Installation does not grant data access. Login startup is explicit opt-in.
Stop the agent before removal; preserve user data and backups.
