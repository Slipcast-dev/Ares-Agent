# Установка Ares

[English](INSTALL.en.md) · [Главная](../README.md)

Текущий выпуск: E10, Apple Silicon, macOS14+, Python3 по пути `/usr/bin/python3`
(обычно предоставляется Command Line Tools). PKG/DMG не имеют подписи
Developer ID и не нотариализованы. Внутренние executable подписаны ad-hoc.
Для обычного локального запуска сертификат разработчика не нужен, однако macOS
может запросить дополнительное ручное разрешение открытия или блокировать пакет.
Не отключайте системную защиту и не обходите корпоративные ограничения.

1. Скачайте DMG и SHA256SUMS.txt из одного выпуска. Можно скачать PKG отдельно,
   но custom icon вне DMG не переносится через HTTP.
2. В каталоге скачанных файлов выполните `shasum -a 256 -c SHA256SUMS.txt`.
   Для проверки всего списка скачайте оба файла — pkg и dmg. Иначе проверяйте
   сумму конкретного скачанного файла по соответствующей строке.
3. Откройте DMG, затем pkg с иконкой Ares. Installer устанавливает
   `/Applications/Ares Intermediate.app`.
4. После явного открытия приложение создаёт отдельный профиль:
   `~/Library/Application Support/SubAgent Intermediates/Ares`.
5. Папки, операции, подключение клиентов и автозапуск подтверждаются отдельно.
   Старые базы и настройки клиентов не импортируются автоматически.

## Управление профилем

```sh
python3 '/Applications/Ares Intermediate.app/Contents/Resources/snapshot_entry.py' status
python3 '/Applications/Ares Intermediate.app/Contents/Resources/snapshot_entry.py' stop
```

Перед обновлением остановите свой профиль. Остановка сохраняет БД и историю.
Удаление приложения не удаляет профиль. Исходные личные файлы не удаляются.
Автозапуск отключите отдельно до удаления приложения, если ранее его включали.
Downgrade бинарников поверх нового inbox document v2 не поддерживается:
используйте согласованную резервную копию состояния.

## Известные ограничения

Промежуточный bootstrap использует Python3; он не поставляется в pkg. Не проверены
Intel, реальная установка/upgrade на чистом Mac, отдельный macOS14 host,
sleep/logout/login, видимый баннер и 24ч. DMG проверен копированием только data
fork: иконка pkg и значок тома сохранились после повторного read-only mount.
